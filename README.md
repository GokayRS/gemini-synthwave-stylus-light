# Gemini Synthwave (Light Mode) 🌆✨

[English](#english) | [Español](#español)

---

## English

Custom light theme for the Google Gemini web interface via Stylus. Designed with a clean, elegant aesthetic, soft pastel backgrounds, vibrant purple headings, and a full-width responsive layout.

### 🌟 Key Features
- **Full-Width Layout:** Maximizes prompt and response space across widescreen monitors.
- **Clean Pastel Palette:** Crisp off-white background (`#F8F9FA`), pure white cards, and soft neutral borders (`#E2E8F0`).
- **Vibrant Typography:** Electric Violet headers (`#5B21B6`), Emerald Green bold highlights (`#047857`), and Magenta accents (`#D946EF`).
- **Clutter Free:** Hides footer disclaimers, upsells, and unnecessary elements.

### 🚀 Installation

1. Install the **Stylus** extension for your browser ([Chrome](https://chrome.google.com/webstore/detail/stylus/clbfbmidbdobicbbnoobnhmoaikkdbec) / [Firefox](https://addons.mozilla.org/en-US/firefox/addon/styl-us/)).
2. Click the link below to install the style directly:
   👉 **[Install Gemini Synthwave Light](https://raw.githubusercontent.com/GokayRS/gemini-synthwave-stylus-light/main/gemini-synthwave-light.user.css)** *(Raw File)*
3. Stylus will open. Click **"Install Style"**.

## Español

Tema claro personalizado para la interfaz web de Google Gemini a través de Stylus. Diseñado con una estética limpia y elegante, fondos pastel suaves, encabezados en púrpura vibrante y un diseño panorámico que aprovecha todo el ancho de la pantalla.

### 🌟 Características Principales
- **Diseño Ancho Completo:** Elimina los márgenes estrechos y aprovecha todo el espacio en monitores panorámicos.
- **Paleta Clara y Suave:** Fondo general blanco grisáceo (`#F8F9FA`), tarjetas en blanco puro y bordes sutiles (`#E2E8F0`).
- **Tipografía Vibrante:** Encabezados en púrpura vibrante (`#5B21B6`), negritas en verde esmeralda (`#047857`) y acentos en magenta (`#D946EF`).
- **Interfaz Limpia:** Oculta avisos del pie de página, promociones de suscripción y líneas divisoras molestas.

### 🚀 Instalación

1. Instala la extensión **Stylus** en tu navegador ([Chrome](https://chrome.google.com/webstore/detail/stylus/clbfbmidbdobicbbnoobnhmoaikkdbec) / [Firefox](https://addons.mozilla.org/es/firefox/addon/styl-us/)).
2. Haz clic en el siguiente enlace para instalar el tema directamente:
   👉 **[Instalar Gemini Synthwave Light](https://raw.githubusercontent.com/GokayRS/gemini-synthwave-stylus/main/gemini-synthwave.user.css)** *(Archivo Raw)*
3. Se abrirá Stylus automáticamente. Pulsa en **"Instalar estilo"**.
